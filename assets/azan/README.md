# Azan Audio Assets

Place your Azan MP3 files here:

| File | Purpose |
|------|---------|
| `makkah.mp3` | Default Azan (Makkah style) |
| `madinah.mp3` | Madinah style Azan |
| `fajr.mp3` | Optional separate Fajr Azan |

The repository includes **short test tones** (3 s sine wave) so the app can be installed and tested without real recordings. Replace them with your own Azan audio before daily use.

**Requirements for AVPlay on Tizen TV:**
- MP3 format recommended
- Use reasonably sized files (under ~10 MB each)
- Absolute paths are resolved at runtime from the app bundle
